# 🌊 Ocean 3D Viz — SIH 2026, PS 26067 (MoES / INCOIS)

A browser-based 3D visualization platform that shows ocean model outputs (temperature, salinity, currents) through the full water column, together with Argo float and glider observations, for the seas around India (0–25°N, 60–100°E).

**Start here:** read [`CONTRACT.md`](CONTRACT.md). Every name, unit and JSON shape the team uses is defined there.

## Quick start (frontend, mock data)
```bash
cd frontend
npm install
npm run dev        # open http://localhost:5173
```

## Data credits
Model data: E.U. Copernicus Marine Service Information, GLOBAL_ANALYSISFORECAST_PHY_001_024 (DOI 10.48670/moi-00016). Observations: the International Argo Program. Coastlines: Natural Earth (public domain).
Mock data in `frontend/public/mock/` is **synthetic** (generated by `tools/make_mock_data.py`) and must never be presented as real.
